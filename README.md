# auto-wechat

A professional automation tool for WeChat, built with Go.

## Prerequisites

- [Go](https://go.dev/doc/install) (version 1.24.1 or higher)

## Development

Use the provided `Makefile` for common development tasks:

```bash
# Build the project
make build

# Run the project
make run

# Format the code
make fmt

# Clean build artifacts
make clean
```

## Debugging

This project includes a VSCode launch configuration. Open the project in VSCode and press `F5` to start debugging.
